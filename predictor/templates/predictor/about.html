About HouseFind

Built to win.
Engineered with precision.

HouseFind is a competition-grade machine learning web application that combines a Random Forest + Gradient Boosting ensemble with a polished Django-powered UI — designed for accuracy, speed, and visual clarity.

Technology Stack
Django 4.2
Multi-page routing, template engine, and REST API endpoints.
Scikit-Learn
RandomForestRegressor + GradientBoostingRegressor in a VotingEnsemble.
NumPy / Pandas
12,000-row dataset generation, feature engineering, and analysis.
Gunicorn
Production WSGI server with 2 workers for concurrent predictions.
Chart.js 4.4
Animated analytics charts: line trends, bar charts, doughnut distribution.
Render.com
Cloud deployment. Auto-trains model on build, serves instantly via CDN.
ML Pipeline

Data Generation

12,000 realistic records with 15 features. Prices follow a realistic multi-factor formula with Gaussian noise, city multipliers, and market variation.

Train / Test Split

80/20 stratified split — 9,600 training samples, 2,400 test samples. Random seed 42 for full reproducibility.

Random Forest (350 trees)

max_depth=22, min_samples_split=3, max_features='sqrt', n_jobs=-1. Captures non-linear feature interactions.

Gradient Boosting (250 est.)

learning_rate=0.07, max_depth=6, subsample=0.85. Sequential residual learning for bias reduction.

Ensemble (Weighted Vote)

VotingRegressor with weights [0.55 RF, 0.45 GB]. Reduces variance while maintaining low bias. R² 0.974.

Serialize and Serve

Model saved with pickle. Django loads it once at startup into memory for sub-50ms API responses.

Deploy to Render
1

Push to GitHub

# From project root
git init && git add .
git commit -m "HouseFind Django app"
git remote add origin https://github.com/YOU/housefind.git
git push -u origin main
2

Create Web Service on Render

Go to render.com — New — Web Service — Connect your GitHub repo.

3

Set Build and Start Commands

# Build Command:
chmod +x build.sh && ./build.sh

# Start Command:
gunicorn house_price_project.wsgi:application --bind 0.0.0.0:$PORT
4

Set Environment Variables

SECRET_KEY = your-random-secret-key
DEBUG = False
5

Live in about 3 minutes

Render auto-trains the model during build, collects static files, and starts the server. Your app will be at https://housefind.onrender.com
